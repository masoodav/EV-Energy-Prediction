# EV Energy Consumption Prediction

This project uses machine learning to estimate energy consumption trends in electric vehicles based on driving behavior, environmental conditions, and derived features. The goal is to support energy-aware route optimization in real-world vehicle systems.

---

## Setup Instructions

To set up the development environment:
Install Anaconda 
Execute following Anaconda prompt
conda create --name ml_projects_venv python=3.11.5
conda activate ml_projects_venv
pip install -r requirements.txt
build.bat
